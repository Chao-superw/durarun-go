# Security policy

Report suspected vulnerabilities through [GitHub private vulnerability reporting](https://github.com/Chao-superw/durarun-go/security/advisories/new). Include the affected version, the impact you observed, and steps to reproduce it. Use sample inputs and remove credentials and private data from logs.

Use [GitHub Issues](https://github.com/Chao-superw/durarun-go/issues) for ordinary bugs. Security fixes, when available, will target the latest preview.
